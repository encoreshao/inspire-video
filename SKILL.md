# InspireVideo (pointer)

This file only keeps installs that still link the repository root working. The skills now live in `skills/`:

- Speaker-footage videos (podcast, interview, speech): read `skills/inspire-video/SKILL.md` and follow it.
- Showcase videos from a website, repository or screenshots: read `skills/inspire-showcase/SKILL.md` and follow it.

Use the repository root (`~/.inspire-video`) as the working directory for every command. Run `bash scripts/install.sh` once to switch to the per-skill links; after that this pointer is no longer used.
